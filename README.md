# Crispy House (diplom layihəsi)
## Server
cd server && npm install && cp .env.example .env   # .env-i Atlas məlumatları ilə doldur
npm run seed   # admin hesabı yaradır (.env-dəki ADMIN_EMAIL / ADMIN_PASSWORD)
npm run dev    # http://localhost:5000
## Client
cd client && npm install && npm run dev   # http://localhost:5173
